# KyrAnime

Сайт для просмотра аниме с кыргызской озвучкой. Каталог, поиск, плеер (HLS), профиль, избранное, «продолжить просмотр», отзывы с оценками, админка. Интерфейс на кыргызском и русском. Палитра: 60% чёрный, 30% белый, 10% ярко-зелёный (`#22ff88`, только акценты).

**Стек:** Next.js 15 (App Router) · Tailwind · Supabase (Postgres + Auth) · hls.js · видео на Cloudflare R2.

## Запуск локально

```bash
npm install
npm run dev
```

Без настроек сайт работает в **демо-режиме** (6 тайтлов, тестовый поток). Регистрация, отзывы и админка включаются после подключения Supabase.

## Подключение базы (Supabase)

1. Создай проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполни весь файл `supabase/schema.sql`. Перед этим замени `CHANGE_ME@example.com` в функции `is_admin()` на свою почту.
3. Скопируй `.env.example` в `.env.local` и заполни:
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` (Project Settings → API)
   - `ADMIN_EMAIL` — та же почта, что в `is_admin()`
   - `NEXT_PUBLIC_CONTACT_EMAIL` — почта для правообладателей (показывается в подвале)
4. Зарегистрируйся на сайте этой почтой: в шапке появится кнопка «Админка».

## Как добавлять серии

1. Конвертируй серию в HLS (720p):

   ```bash
   mkdir -p ep01 && ffmpeg -i ep01.mp4 \
     -vf scale=-2:720 -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 128k \
     -hls_time 6 -hls_playlist_type vod \
     -hls_segment_filename "ep01/seg_%04d.ts" ep01/index.m3u8
   ```

2. Загрузи папку `ep01/` в Cloudflare R2 (bucket с публичным доступом или своим доменом). Для плеера в R2 нужно включить CORS для адреса сайта.
3. В `/admin` создай тайтл, затем серию и вставь ссылку на `index.m3u8`.

40 серий по 20–25 минут в 720p занимают примерно 6–12 ГБ.

## Структура

| Путь | Что делает |
|---|---|
| `src/app/page.tsx` | Главная: каталог, «продолжить просмотр» |
| `src/app/search` | Поиск по названиям (кыргызское, русское, оригинал) |
| `src/app/anime/[slug]` | Страница тайтла: серии, отзывы, избранное |
| `src/app/watch/[slug]/[ep]` | Плеер. Адрес серии: `/watch/one-piece/1-12` (сезон-номер) |
| `src/app/profile` | Профиль, избранное, прогресс |
| `src/app/admin` | Добавление тайтлов и серий (только `ADMIN_EMAIL`) |
| `src/app/actions.ts` | Server actions: вход, отзывы, избранное, прогресс, админка |
| `src/lib/i18n.ts` | Переводы KG/RU |
| `supabase/schema.sql` | Таблицы и правила доступа (RLS) |

## Права и безопасность

- Запись в каталог разрешена только админу (политики RLS в базе, а не только в интерфейсе).
- Отзывы, избранное и прогресс видит и меняет только их владелец (отзывы читают все).
- В подвале есть блок «Для правообладателей» с почтой для жалоб. Если придёт жалоба, снимай серию через базу (`published = false`).
- Это фанатская озвучка: оригинальные аниме принадлежат студиям. Храни свои озвучки и исходники отдельно от хостинга.
